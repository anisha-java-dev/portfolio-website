# Anisha Chavan — Full Stack Developer Portfolio

A responsive, minimalist personal portfolio website built to showcase my Java Full Stack and React development projects, technical skill set, and resume.

## Tech Stack
- **Frontend:** React.js, JavaScript (ES6+), Tailwind CSS, Lucide React
- **Build Tool:** Vite
- **Integrations:** EmailJS (Contact Form), Browser LocalStorage (Theme Persistence)

## Key Features
- **Responsive Design:** Adapts cleanly across mobile, tablet, and desktop screens.
- **Dark & Light Mode:** Theme switcher that remembers user preferences across visits.
- **Project Filtering:** Dynamic category filtering (`All`, `Java`, `React`) using React state.
- **Working Contact Form:** Input validation with real-time email delivery via EmailJS.
- **Resume Access:** One-click resume viewing and downloading.
